# adrianzhi.github.io

王志寬（Adrianzhi Kuan Ong）個人資訊與研究觀點網站。

## 上傳圖片

請把原始圖片放入 `images` 文件夾，並保持以下檔名：

- `1.png`、`2.png`、`3.png`、`4.png`、`5.png`、`6.png`
- `IMG_1479.png`、`IMG_1480.png`、`IMG_1481.png`、`IMG_1482.png`

若圖片尚未上傳，頁面會自動顯示 `placeholder.svg` 備用圖，不會出現破圖。

## 發布

將壓縮包內全部檔案上傳到 GitHub 倉庫 `adrianzhi.github.io` 的根目錄，啟用 GitHub Pages 後即可使用。
